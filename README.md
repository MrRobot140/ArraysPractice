# Java Arrays Practice

A collection of Java practice exercises focused on arrays, loops, conditional statements, and user input.

## 📚 Tasks

This project contains 5 exercises:

1. **Count Positive, Negative, and Zero Values** — Count positive, negative, and zero numbers in an array.
2. **Largest and Smallest Elements** — Find the maximum and minimum values and their indices.
3. **Numbers Greater Than the Average** — Calculate the average and count elements above it.
4. **Print an Array in Reverse Order** — Display array elements in reverse order without modifying the original array.
5. **Student Test Scores** — Input student scores, validate them, count passed and failed scores, and calculate the average.

## 🛠️ Technologies

- Java
- IntelliJ IDEA
- Git & GitHub

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in IntelliJ IDEA.
3. Open the `src` folder.
4. Run any task separately (`Task1.java` – `Task5.java`).

## 🎯 Learning Goals

- Understanding Java arrays.
- Practicing `for` and `while` loops.
- Working with conditional statements.
- Using `Scanner` for user input.
- Calculating sums and averages.
- Finding minimum and maximum values.
